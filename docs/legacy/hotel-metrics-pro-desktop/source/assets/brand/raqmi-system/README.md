# Identité visuelle Raqmi System

Version 1.0 - Août 2026

## Concept

Le symbole fusionne le `Q` latin et le `ق` arabe. Les deux points donnent au signe son ancrage arabe, tandis que la diagonale exprime le mouvement des données et la prise de décision.

Signature de marque : **Un système. Toute votre entreprise.**

## Typographies recommandées

- Logotype : dessin personnalisé fourni dans les fichiers SVG.
- Interface latine : Manrope.
- Interface arabe : IBM Plex Sans Arabic ou Noto Kufi Arabic.
- Documents bureautiques : Arial et Arial Arabic en remplacement.

## Arborescence

- `svg/` : fichiers maîtres pour impression et intégration.
- `png/` : logos transparents en plusieurs résolutions.
- `jpg/` : logos sur fonds clair et sombre.
- `icons/` : icônes application Windows et formats PNG.
- `digital/` : écran de démarrage, réseaux sociaux, présentation et e-mail.
- `stationery/` : cartes, papier à en-tête et en-tête de document.
- `brand-guide/` : charte graphique complète.

## Règles essentielles

1. Ne jamais déplacer ou supprimer les deux points du qaf.
2. Ne pas déformer, incliner ou recomposer le logotype.
3. Utiliser la version blanche sur fond sombre et la version couleur sur fond clair.
4. Préserver une zone libre au moins égale à la hauteur d'un point autour du symbole.
5. Utiliser `RaqmiSystem.ico` pour l'application Windows.
