# Guide utilisateur — PDG / Direction générale

## Rôle

Le profil PDG permet de suivre l'activité globale de l'entreprise, de consulter les indicateurs consolidés, les alertes stratégiques, les rapports et les décisions.

## Accès principaux

- Dashboard consolidé.
- Résultats par unité.
- Objectifs et réalisations.
- Rapports PDF/Excel.
- Recettes validées.
- Facturation et recouvrement en consultation.
- RH consolidé en consultation direction.
- Décisions, réclamations et anomalies majeures.

## Tâches quotidiennes

1. Consulter le dashboard global.
2. Vérifier le chiffre d'affaires de la veille.
3. Identifier les unités en retard ou en baisse.
4. Lire les alertes importantes.
5. Suivre les décisions en attente.

## Procédures principales

### Consulter la performance globale

1. Aller dans `Dashboard`.
2. Choisir la période.
3. Comparer réalisé, budget et N-1.
4. Identifier les unités en écart négatif.
5. Exporter le rapport si nécessaire.

### Suivre les décisions

1. Aller dans `Décisions`.
2. Filtrer par priorité ou statut.
3. Lire les décisions en attente.
4. Vérifier les échéances.

### Consulter le recouvrement

1. Aller dans `Facturation` ou `Recouvrement`.
2. Filtrer les factures échues.
3. Identifier les gros débiteurs.
4. Demander une action au service concerné.

## Points de contrôle

- CA quotidien reçu avant l'heure fixée.
- Objectifs mensuels comparés au réalisé.
- Factures échues suivies.
- Réclamations critiques traitées.
- Décisions importantes historisées.

## Erreurs fréquentes

- Lire uniquement le CA sans regarder l'encaissement.
- Comparer deux périodes sans tenir compte de la saisonnalité.
- Valider une décision sans document justificatif.

## Règles de sécurité

- Ne jamais partager son compte.
- Exporter les rapports uniquement si nécessaire.
- Éviter les modifications opérationnelles directes si un service métier doit les traiter.
