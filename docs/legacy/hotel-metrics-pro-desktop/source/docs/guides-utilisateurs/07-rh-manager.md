# Guide utilisateur — Responsable RH

## Rôle

Le responsable RH gère les collaborateurs, contrats, absences, congés, paie, formations, compétences, entretiens et documents RH.

## Accès principaux

- Dashboard RH.
- Collaborateurs.
- Contrats.
- Temps et absences (planning, pointages, **réconciliation H+15**).
- Paie certifiable DZ (HS, retenues, exports CNAS/DADS-U).
- Recrutement ATS (pipeline, offres, entretiens).
- GPEC et campagnes d'évaluation.
- Formations.
- Compétences.
- Entretiens.
- Documents RH.
- Référentiel RH.

## Tâches quotidiennes

1. Vérifier les nouvelles demandes RH.
2. Suivre les absences et congés.
3. Contrôler les contrats arrivant à échéance.
4. Mettre à jour les dossiers collaborateurs.
5. Suivre les éléments variables de paie.
6. Vérifier les documents manquants ou expirés.

## Procédures principales

### Créer ou mettre à jour un collaborateur

1. Aller dans `RH > Collaborateurs`.
2. Créer ou ouvrir la fiche.
3. Renseigner identité, unité, poste, contrat et statut.
4. Ajouter les documents nécessaires.
5. Enregistrer et vérifier l'historique.

### Suivre une absence

1. Aller dans `RH > Temps` ou `RH > Absences`.
2. Sélectionner le collaborateur.
3. Vérifier la période.
4. Contrôler le justificatif.
5. Valider ou refuser selon la procédure interne.

### Préparer la paie

1. Aller dans `RH > Paie`.
2. Vérifier la période.
3. Contrôler les absences, primes, retenues et éléments variables.
4. Lancer le calcul ou la simulation.
5. Exporter uniquement après contrôle.

## Points de contrôle

- Aucun collaborateur sans statut clair.
- Aucun contrat expiré sans décision.
- Les absences sont justifiées.
- Les éléments de paie sont contrôlés.
- Les documents RH sensibles sont protégés.

## Erreurs fréquentes

- Modifier une période de paie après validation.
- Oublier une fin de CDD.
- Valider une absence sans justificatif.
- Créer un doublon collaborateur.

## Règles de sécurité

- Les données RH sont confidentielles.
- Les exports paie doivent être limités aux personnes habilitées.
- Toute modification de contrat doit être historisée.
- Les documents collaborateurs ne doivent pas être téléchargés inutilement.
