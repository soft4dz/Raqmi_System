# Guide utilisateur — Responsable PortMaster

## Rôle

Le responsable PortMaster gère l'activité portuaire : clients, bateaux, emplacements, contrats, mouvements, factures portuaires, validations et recouvrement lié au port.

## Accès principaux

- Dashboard PortMaster.
- Clients portuaires.
- Bateaux.
- Emplacements.
- Contrats.
- Tarifs portuaires.
- Factures portuaires.
- Mouvements.
- Recouvrement portuaire.
- Validations.

## Tâches quotidiennes

1. Vérifier les mouvements de bateaux.
2. Contrôler les contrats actifs et expirés.
3. Suivre les factures en attente.
4. Identifier les clients en retard de paiement.
5. Mettre à jour les informations bateau/client.
6. Suivre les emplacements disponibles et occupés.

## Procédures principales

### Créer un client portuaire

1. Aller dans `PortMaster > Clients`.
2. Cliquer sur `Nouveau client`.
3. Renseigner les informations d'identité et de contact.
4. Enregistrer.
5. Vérifier que le client est bien disponible pour contrat ou bateau.

### Ajouter un bateau

1. Aller dans `PortMaster > Bateaux`.
2. Cliquer sur `Nouveau bateau`.
3. Sélectionner le propriétaire.
4. Renseigner immatriculation, dimensions et caractéristiques.
5. Ajouter les documents si le module GED est activé.

### Suivre un contrat

1. Aller dans `PortMaster > Contrats`.
2. Ouvrir le contrat.
3. Vérifier dates, emplacement, tarif et statut.
4. Générer ou suivre la facturation liée.
5. Surveiller l'expiration.

## Points de contrôle

- Aucun bateau sans propriétaire identifié.
- Aucun contrat actif sans période claire.
- Aucun emplacement occupé sans statut cohérent.
- Factures portuaires suivies.
- Clients débiteurs identifiés.

## Erreurs fréquentes

- Affecter un emplacement déjà occupé.
- Créer un contrat sans vérifier la période.
- Oublier les documents bateau.
- Confondre mouvement temporaire et contrat actif.

## Règles de sécurité

- Les données clients et bateaux sont confidentielles.
- Toute modification de contrat doit être justifiée.
- Les tarifs ne doivent être modifiés que par profil habilité.
- Les factures doivent rester traçables.
