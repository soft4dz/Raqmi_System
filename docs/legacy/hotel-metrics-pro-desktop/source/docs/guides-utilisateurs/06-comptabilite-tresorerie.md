# Guide utilisateur — Comptabilité / Trésorerie

## Rôle

Le profil comptabilité/trésorerie suit les encaissements, la caisse, les comptes bancaires, les factures, les paiements, les écarts et le recouvrement.

## Accès principaux

- Encaissements.
- Journal de caisse.
- Comptes bancaires.
- Facturation.
- Paiements.
- Clients.
- Recouvrement.
- Rapports financiers.

## Tâches quotidiennes

1. Vérifier les encaissements saisis.
2. Contrôler le journal de caisse.
3. Suivre les paiements reçus.
4. Identifier les factures échues.
5. Comparer les recettes avec les encaissements.
6. Préparer les états de trésorerie.

## Procédures principales

### Saisir un encaissement

1. Aller dans `Encaissements > Nouveau`.
2. Sélectionner le client ou l'origine.
3. Choisir le mode de paiement.
4. Renseigner le montant, la date et la référence.
5. Enregistrer.
6. Vérifier l'impact dans le journal.

### Suivre les factures

1. Aller dans `Facturation > Factures`.
2. Filtrer par statut.
3. Ouvrir la facture concernée.
4. Vérifier les paiements affectés.
5. Mettre à jour le suivi si nécessaire.

### Contrôler la caisse

1. Aller dans `Encaissements > Caisse`.
2. Choisir la date.
3. Comparer les mouvements saisis avec les pièces justificatives.
4. Signaler tout écart.

## Points de contrôle

- Aucun encaissement sans référence.
- Aucune facture validée sans client.
- Les paiements partiels sont bien affectés.
- Les écarts caisse sont justifiés.
- Les factures échues sont suivies.

## Erreurs fréquentes

- Affecter un paiement au mauvais client.
- Confondre facture proforma et facture validée.
- Oublier les paiements partiels.
- Corriger un encaissement sans motif.

## Règles de sécurité

- Les corrections financières doivent être justifiées.
- Les exports financiers doivent être conservés avec date et période.
- Aucune suppression sans validation hiérarchique.
- Les comptes bancaires doivent être strictement réservés aux profils habilités.
