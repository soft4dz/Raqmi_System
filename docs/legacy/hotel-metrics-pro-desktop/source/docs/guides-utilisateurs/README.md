# Guides utilisateurs — Raqmi System

Ce dossier regroupe les guides par profil utilisateur. L'objectif est simple : chaque utilisateur doit savoir quoi faire, où le faire, et ce qu'il ne doit surtout pas bricoler dans l'application.

## Profils couverts

| Guide | Profil | Usage principal |
|---|---|---|
| `00-manuel-general.md` | Tous | Vue d'ensemble, modules, nouveautés |
| `01-super-admin.md` | Super administrateur | Paramétrage global, sécurité, sauvegarde, modules |
| `02-pdg.md` | PDG / Direction générale | Lecture consolidée, pilotage, décisions |
| `03-directeur-unite.md` | Directeur d'unité | Suivi de son unité, recettes, exploitation, alertes |
| `04-controleur-exploitation.md` | Contrôleur exploitation / DEC | Contrôle, validation, reporting, anomalies |
| `05-responsable-portmaster.md` | Responsable port | PortMaster, bateaux, contrats, factures portuaires |
| `06-comptabilite-tresorerie.md` | Comptabilité / trésorerie | Encaissements, caisse, factures, paiements, recouvrement |
| `07-rh-manager.md` | Responsable RH | Collaborateurs, contrats, absences, paie, formations |
| `08-chef-departement.md` | Chef de département | Suivi opérationnel, demandes, anomalies, maintenance |
| `09-receptionniste.md` | Réceptionniste | Hébergement, clients, réservations, check-in/check-out |
| `10-audit-interne.md` | Audit interne | Journaux, contrôles, traçabilité, rapports |
| `11-lecture-seule.md` | Lecture seule | Consultation sans modification |

## Structure recommandée de chaque guide

Chaque guide contient :

1. rôle du profil ;
2. accès autorisés ;
3. tâches quotidiennes ;
4. procédures principales ;
5. points de contrôle ;
6. erreurs fréquentes ;
7. règles de sécurité ;
8. assistance et escalade.

## Règle de mise à jour

Toute évolution fonctionnelle importante doit être accompagnée d'une mise à jour du guide concerné. Ajouter une fonctionnalité sans guide, c'est offrir un labyrinthe et appeler ça transformation digitale.
