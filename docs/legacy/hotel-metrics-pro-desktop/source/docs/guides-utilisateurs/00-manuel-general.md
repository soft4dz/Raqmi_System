# Manuel d'utilisation — Raqmi System

## Bienvenue

Ce manuel regroupe l'ensemble des guides par profil utilisateur pour **Raqmi System** (Raqmi System). Chaque guide décrit les accès autorisés, les tâches quotidiennes et les procédures pas à pas.

## Comment utiliser ce module

1. Ouvrez **Aide & guides** dans le menu latéral.
2. Consultez le guide suggéré selon votre rôle, ou parcourez le catalogue.
3. Utilisez la recherche pour trouver une procédure (ex. « clôture », « paie », « POS »).

## Modules principaux

| Module | Chemin | Usage |
|--------|--------|-------|
| Pilotage | Dashboard, DEC, PDG | KPIs consolidés, décisions |
| Exploitation | Recettes, trésorerie, facturation | Saisie et validation quotidienne |
| Opérations | Stocks, cuisine, POS, achats | Production et ventes |
| RH | `/rh` | Collaborateurs, temps, paie, talents |
| PortMaster | `/portmaster` | Port de plaisance, amarrage |
| Contrôle | Workflows, checklists, audit | Conformité interne |
| Système | Paramètres, sauvegarde | Administration technique |

## RH — nouveautés récentes

- **Paie certifiable DZ** : HS, retenues, exports CNAS/DADS-U (`RH > Paie`)
- **Recrutement ATS** : pipeline Kanban, offres, entretiens (`RH > Talents > Recrutements`)
- **Réconciliation temps** : planning vs pointage, alertes H+15 (`RH > Temps > Réconciliation`)
- **GPEC** : campagnes d'évaluation et matrice compétences (`RH > Talents > GPEC`)

## Ordre des clôtures (hôtel + POS)

```
1. Clôture session POS (par faction)
2. Clôture journée POS (par point de vente)
3. Clôture hôtel (/recettes/cloture)
```

## Assistance

- Guide adapté à votre rôle : voir la suggestion en haut du catalogue.
- Super administrateur : paramètres système, sauvegarde, modules.
- En cas de blocage : consulter le journal d'audit (`Système > Journal d'audit`).
