# Guide utilisateur — Lecture seule

## Rôle

Le profil lecture seule permet de consulter les informations autorisées sans pouvoir modifier, supprimer, valider ou créer des données.

## Accès principaux

- Dashboard selon périmètre.
- Rapports en consultation.
- Données d'exploitation en consultation.
- Recettes validées selon droits.
- Factures ou clients en consultation selon habilitation.

## Tâches quotidiennes

1. Consulter les indicateurs utiles.
2. Lire les rapports mis à disposition.
3. Vérifier les données de son périmètre.
4. Signaler toute incohérence à un profil habilité.

## Procédures principales

### Consulter un rapport

1. Aller dans `Rapports`.
2. Choisir la période.
3. Appliquer les filtres autorisés.
4. Lire les résultats.
5. Demander un export à un profil habilité si nécessaire.

### Consulter un dashboard

1. Aller dans `Dashboard`.
2. Choisir la période si le filtre est disponible.
3. Lire les indicateurs.
4. Ne pas interpréter une anomalie sans vérifier la source.

## Points de contrôle

- Les données consultées correspondent au bon périmètre.
- Les périodes sont correctement sélectionnées.
- Les anomalies sont signalées au service concerné.

## Erreurs fréquentes

- Capturer ou diffuser des informations sensibles.
- Interpréter un chiffre provisoire comme définitif.
- Demander un accès supérieur sans justification métier.

## Règles de sécurité

- Ne pas partager les captures ou exports.
- Ne pas utiliser le compte d'un autre utilisateur pour modifier une donnée.
- Respecter le périmètre autorisé.
- Signaler toute information incohérente au responsable concerné.
