# Guide utilisateur — Chef de département

## Rôle

Le chef de département suit les activités de son service, déclare les anomalies, suit les demandes de maintenance, consulte les indicateurs utiles et participe au traitement opérationnel.

## Accès principaux

- Dashboard limité à son périmètre.
- Anomalies.
- Maintenance.
- Stocks selon habilitation.
- Achats ou demandes internes selon habilitation.
- Réclamations liées au service.
- Décisions ou instructions reçues.

## Tâches quotidiennes

1. Vérifier les anomalies affectées au service.
2. Déclarer les incidents constatés.
3. Suivre les demandes maintenance.
4. Vérifier les besoins en stock ou fournitures.
5. Répondre aux instructions opérationnelles.

## Procédures principales

### Déclarer une anomalie

1. Aller dans `Anomalies`.
2. Cliquer sur `Nouvelle anomalie`.
3. Décrire le problème clairement.
4. Choisir le niveau de priorité.
5. Affecter le service concerné si nécessaire.
6. Ajouter une photo ou pièce si disponible.

### Suivre une intervention maintenance

1. Aller dans `Maintenance`.
2. Filtrer les interventions de son service.
3. Vérifier le statut.
4. Relancer si l'intervention est urgente.
5. Confirmer la résolution réelle.

### Demander un achat ou signaler un besoin

1. Aller dans `Achats` ou `Stocks` selon l'accès.
2. Créer une demande ou signaler le besoin.
3. Justifier la demande.
4. Suivre le statut jusqu'à traitement.

## Points de contrôle

- Les anomalies sont décrites précisément.
- Les urgences sont correctement classées.
- Les besoins sont justifiés.
- Les actions clôturées sont réellement terminées.

## Erreurs fréquentes

- Créer plusieurs anomalies pour le même problème.
- Mettre toutes les demandes en urgence.
- Clôturer une action sans vérification terrain.
- Oublier les pièces justificatives.

## Règles de sécurité

- Ne pas modifier des données hors périmètre.
- Ne pas supprimer une anomalie pour masquer un problème.
- Utiliser des descriptions factuelles.
- Éviter les informations personnelles inutiles dans les commentaires.
