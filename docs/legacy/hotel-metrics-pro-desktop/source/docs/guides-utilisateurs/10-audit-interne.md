# Guide utilisateur — Audit interne

## Rôle

Le profil audit interne consulte les journaux, vérifie la traçabilité des opérations, contrôle les modifications sensibles et prépare les constats ou rapports d'audit.

## Accès principaux

- Journaux d'audit.
- Rapports.
- Recettes en consultation.
- Facturation en consultation.
- RH en consultation limitée selon habilitation.
- Anomalies.
- Décisions.
- GED en consultation selon droits.

## Tâches quotidiennes ou périodiques

1. Contrôler les modifications sensibles.
2. Vérifier les connexions inhabituelles.
3. Identifier les suppressions ou corrections fréquentes.
4. Contrôler les validations tardives.
5. Préparer les rapports d'audit.

## Procédures principales

### Consulter les journaux d'audit

1. Aller dans `Audit > Logs`.
2. Filtrer par utilisateur, période, module ou action.
3. Lire le détail de l'opération.
4. Exporter uniquement si nécessaire.
5. Joindre les éléments au dossier d'audit.

### Contrôler les corrections de recettes

1. Aller dans `Recettes > Historique`.
2. Filtrer les périodes concernées.
3. Identifier les lignes modifiées ou supprimées.
4. Vérifier le motif.
5. Comparer avec l'audit.

### Préparer un constat

1. Collecter les logs et captures nécessaires.
2. Décrire les faits sans interprétation inutile.
3. Mentionner date, utilisateur, module et action.
4. Transmettre selon la procédure interne.

## Points de contrôle

- Toute correction sensible doit avoir un motif.
- Toute suppression doit être justifiée.
- Les comptes utilisateurs doivent être individuels.
- Les accès élevés doivent être limités.
- Les exports doivent être maîtrisés.

## Erreurs fréquentes

- Confondre anomalie technique et faute utilisateur.
- Exporter trop de données sensibles.
- Tirer une conclusion sans vérifier le journal complet.
- Oublier de préciser la période auditée.

## Règles de sécurité

- Les données d'audit sont confidentielles.
- Ne jamais modifier les données contrôlées.
- Conserver les preuves de manière sécurisée.
- Respecter le périmètre d'audit autorisé.
