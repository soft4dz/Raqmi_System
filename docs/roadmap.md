# Roadmap

## Phase 0 - Technical foundation

- Create repository structure
- Choose .NET 10 LTS
- Prepare solution and project boundaries
- Add CI workflow
- Add first tests

## Phase 1 - Security foundation

- Authentication
- Roles and permissions
- Password policy
- Audit log
- Secret management
- License model

## Phase 2 - Daily revenue pilot

- Hotel units API
- Daily revenue entry API
- Draft, submit, validate and reject workflow
- PostgreSQL schema and seed data for the first EGT units
- Direction summary endpoint
- Export and print reports
- Desktop screens for unit and daily revenue entry

## Phase 3 - Core finance and exploitation

- Treasury and cash desk
- Invoicing
- Client accounts
- PMS room availability
- Reservation workflow
- Reporting by unit and consolidated reporting

## Phase 4 - Extended ERP modules

- Stocks and purchasing
- HR and payroll
- Accounting exports
- Maintenance
- Port and parking operations
- Document management

## Phase 5 - Industrialization

- Installer
- Server-client deployment
- Backup and restore
- Monitoring
- Data migration
- Pilot in one hotel unit
- Progressive rollout to all units
