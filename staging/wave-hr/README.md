# Zone de préparation — module RH (paie)

Ces quatre fichiers de domaine (barème IRG paramétré, paramètres de paie,
calcul de bulletin) ont été produits par un agent au cours d'une autre vague,
sans service, sans endpoint, sans écran et sans test : personne ne les
référençait.

Ils ont été sortis de l'arbre compilé plutôt que supprimés : le travail est
correct — le barème est **injecté, jamais codé en dur**, donc rien de
réglementaire n'y est inventé — et servira de point de départ à la vague RH.

**À ne pas réintégrer tel quel** : ce code n'a jamais été relu ni testé. La
vague RH devra le reprendre, le compléter (service, API, écran, tests) et le
soumettre aux revues comme tout autre module. Les taux et tranches devront
être saisis par l'établissement et validés par un comptable, jamais présentés
comme la référence légale.
