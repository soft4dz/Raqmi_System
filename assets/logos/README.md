# Logos — dossier projet

Logos versionnés avec le code source :

| Fichier | Usage |
|---------|--------|
| `app-logo.svg` | Symbole Q + ق de Raqmi System (icône compacte) |
| `app-wordmark.svg` | Signature Raqmi System pour fond clair |
| `app-wordmark-white.svg` | Signature Raqmi System pour fond sombre |
| `app-bilingual.svg` | Signature français–arabe pour fond clair |
| `app-bilingual-white.svg` | Signature français–arabe pour fond sombre |
| `default-hotel.svg` | Placeholder quand un hôtel n'a pas de logo |

À l'exécution, ces fichiers sont copiés dans le dossier applicatif :

`%AppData%/hotel-metrics-pro-desktop/data/logos/assets/`

Les logos des hôtels sont enregistrés dans :

`%AppData%/hotel-metrics-pro-desktop/data/logos/hotels/{uuid}.png`

Le nom technique historique du dossier est conservé pour retrouver automatiquement les données
des installations antérieures. Il n'est pas affiché dans l'interface Raqmi System.
